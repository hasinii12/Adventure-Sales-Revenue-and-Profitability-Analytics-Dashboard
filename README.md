# 📊 Adventure Sales, Revenue & Profitability Analytics Dashboard

## 📌 Project Overview
This project showcases an interactive Power BI dashboard developed using Excel-based sales data to analyze sales performance, revenue trends, profitability, inventory levels, and customer loyalty across products and countries.  
The dashboard supports data-driven decision-making through KPIs, trend analysis, and dynamic filters.

---

## 🎯 Objectives
- Analyze country-wise and product-wise sales performance
- Track net revenue, gross revenue, and profit margins
- Identify top-performing products
- Monitor sales and profitability trends over time

---

## 🔍 Key Features
- KPIs: Total Stock, Quantity Purchased, Median Sales, Net Revenue, YTD Profit Margin  
- Sales Analysis: Loyalty points by country, quantity sold by product  
- Revenue Analysis: Net revenue by product, gross revenue trends  
- Profitability Analysis: Yearly and time-based profit margin insights  
- Interactive Filters: Date range and country slicers
